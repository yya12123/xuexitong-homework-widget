# 学习通作业悬浮窗

> A dark translucent Windows desktop widget for Chaoxing/Xuexitong homework deadlines.

一个常驻在 Windows 桌面右下角的深色半透明小窗，自动登录学习通，按「还剩多少小时」从少到多显示还没交的作业。它固定在桌面层：普通窗口会盖住它，按 Win+D 或最小化窗口就能看到。

## 功能

- 自动同步学习通当前在修课程的作业（只含作业，不含考试/章节测验）
- 每条显示：作业名、课程名、截止时间、剩余小时
- 按剩余时间从少到多排序，左侧显示 01、02、03… 编号
- 深色半透明圆角卡片，白色半透明文字；始终在桌面层、普通窗口之下，不会盖住任何应用
- 可拖动标题栏移动；拖任意边/角可自由改大小
- 作业多时右侧出现细滑块，可拖动/滚轮滚动
- 默认 60 分钟自动刷新，底部显示刷新倒计时；菜单可改 30/60/120 分钟
- 开启「显示已截止作业」后，默认只显示近 1 个月内；菜单可切换「近 7 天 / 近 1 个月」
- 窗口尺寸和位置会自动保存；首次运行默认放在主屏右下角工作区
- 首次启动自动放到主屏右下角工作区（会避开任务栏，适配 2K/125% 缩放）
- 开机自动启动（首次运行会自动创建启动文件夹快捷方式）
- 点击某条作业会用浏览器打开学习通作业页
- 菜单里可切换「显示已截止作业」及近 7 天/近 1 个月范围、账号密码、开机自启、立即刷新、退出

## 启动

运行：

    dist\XuexitongWidget.exe

首次运行会弹出登录框，输入你自己的学习通手机号和密码；密码用 Windows DPAPI 加密保存在本机，不会上传。关掉窗口即退出；下次登录 Windows 会自动启动，首次运行会自动创建启动文件夹快捷方式。它平时在桌面层，按 Win+D / 显示桌面即可看到。

## 文件说明

- dist/XuexitongWidget.exe —— 主程序
- dist/config.json —— 账号、加密后的密码、窗口位置、刷新设置
- dist/cache.json —— 上次同步结果，启动时先显示缓存再后台刷新
- dist/app.log —— 运行/错误日志
- src/ —— C# 源码
- build.ps1 —— 重新编译脚本（使用 Windows 自带的 .NET Framework 4.8 编译器）
- app.manifest —— DPI 适配
- app.ico —— 程序图标

密码使用 Windows DPAPI（当前用户）加密保存，不在源码或日志里保存明文。换 Windows 用户或换电脑后，需要打开菜单 → 账号与密码重新输入。

## 常见问题

- **登录失败**：点右上角「⋯」→ 账号与密码，重新输入学习通手机号和密码。
- **同步失败**：先检查网络；错误提示会显示在窗口顶部，点「重试」。详细原因见 dist/app.log。
- **没有显示作业**：确认学习通网页端「作业」里确实有未提交的作业；已批阅/待批阅的作业不会显示。
- **移动了文件夹**：重新运行一次 exe，程序会自动把开机自启快捷方式指向新位置。
- **桌面上看不到**：它在桌面层，普通窗口会盖住它；按 Win+D 或最小化所有窗口即可看到。
- **关闭后怎么再打开**：运行程序文件夹里的 exe；下次开机也会自动启动（仍在桌面层）。
- **多显示器/缩放**：窗口位置会记住；首次运行会放在主显示器工作区右下角，不压任务栏。

## 卸载

在菜单里关闭「开机自动启动」，删除程序文件夹即可。

## 重新编译

在 Windows 上双击运行 build.ps1，或：

    powershell -ExecutionPolicy Bypass -File build.ps1

生成的 exe 在 dist\XuexitongWidget.exe。

## 系统要求

- Windows 10 / 11（x64）
- .NET Framework 4.8（Windows 10 / 11 自带）
